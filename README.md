# Crystallographic-plane-and-euler-angle-visualisation

An interactive web-based visualization tool for exploring crystallographic orientations, Euler angles, and crystallographic planes in **hexagonal (HCP)** and **cubic** crystal systems. The application provides real-time 3D visualization of the crystal, selected crystallographic plane, orientation matrix, pole figure projection, and the relationship between crystal and sample reference frames.

**🌐 Live Demo:** https://shirishchandrakar.github.io/Crystallographic-plane-and-euler-angle-visualisation/
---
## Overview
Understanding how crystallographic planes transform with crystal orientation is fundamental to texture analysis, EBSD, crystal plasticity, and materials science. This application allows users to interactively modify Bunge Euler angles and Miller indices while immediately visualizing the resulting orientation in three dimensions.
The viewer runs entirely inside a web browser using **Three.js**, requiring no installation or external software.

---
## Features

### Crystal Systems
- Hexagonal (HCP) crystal system
- Cubic crystal system

### Interactive Orientation
- Bunge Euler angles (φ₁, Φ, φ₂)
- Real-time orientation updates
- Orientation matrix display
- Crystal and sample coordinate systems

### Crystallographic Planes
- Interactive Miller index input
- Miller-Bravais notation for HCP
- Built-in plane presets
- Display of plane normal
- Visualization of complete {hkl} plane families

### Crystal Geometry
- True hexagonal prism for HCP crystals
- Cubic unit cell for cubic crystals
- Crystal axes visualization
- Sample axes (RD, TD, ND)

### Pole Figure
- Upper hemisphere projection
- Pole position updates in real time
- Polar and azimuthal angle readout
- Family pole visualization

### Navigation
- Rotate by dragging
- Zoom using mouse wheel
- Camera reset
- Euler angle reset
